Free 24/7 Backend Setup

PulseRoom uses Firebase Realtime Database. To allow this public anonymous chat to work, publish the rules below in Firebase Console → Realtime Database → Rules. These rules allow anyone to read and post validated messages; they are suitable for a small demo, not a heavily abused public service.

  1. Create a free project at console.firebase.google.com.
  2. Go to Build → Realtime Database and create a database in the correct region.
  3. Configure database security rules. Do not leave unrestricted public write access enabled for a public website; add validation and abuse protection before launch.
  4. Your Firebase web app configuration is already included in this page.
  5. Publish the exact rules below. A test of the database root / may be denied; test /rooms/public-lobby instead.
  6. Host index.html on GitHub Pages, Cloudflare Pages, or Netlify.

Realtime Database Rules

{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        "$messageId": {
          ".write": "!data.exists()",
          ".validate": "newData.hasChildren(['sender','text','ts']) && newData.child('sender').isString() && newData.child('sender').val().length <= 40 && newData.child('text').isString() && newData.child('text').val().length > 0 && newData.child('text').val().length <= 500 && newData.child('ts').isNumber()"
        }
      }
    }
  }
}

Public access: anyone can read and post. Add stronger abuse protection before sharing widely.
